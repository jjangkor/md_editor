# JJANG's MD Editor

JJANG's MD Editor - 별도의 빌드 과정 없이 즉시 실행 가능한 단일 파일 마크다운 에디터입니다.

![License](https://img.shields.io/badge/license-MIT-green)
![Build](https://img.shields.io/badge/build-standalone-brightgreen)
![CI](https://github.com/jjangkor/md_editor/actions/workflows/ci.yml/badge.svg)

## 주요 특징

- ✅ **단일 HTML 파일**: 모든 코드가 하나의 `md_editor.html` 파일에 포함
- ✅ **빌드 불필요**: 브라우저에서 바로 실행 가능
- ✅ **CDN 기반**: 모든 라이브러리를 CDN으로 로드하여 별도 설치 불필요
- ✅ **반응형 레이아웃**: 데스크톱 가로 분할과 모바일 세로 분할 자동 전환
- ✅ **실시간 미리보기**: 입력과 동시에 마크다운 렌더링
- ✅ **스크롤 동기화**: 에디터와 프리뷰 창의 스크롤 자동 동기화
- ✅ **자동 목차 생성**: `<!-- TOC -->` 주석으로 자동 목차 생성
- ✅ **수학 수식 지원**: LaTeX 문법으로 수식 작성 및 KaTeX 렌더링
- ✅ **크기 조절 가능**: 에디터와 프리뷰 창 크기를 자유롭게 조절
- ✅ **계층적 리스트**: 불릿(□→○→●)과 자동 번호(1→1.1→1.1.1) 지원
- ✅ **찾기/바꾸기**: 텍스트 검색 및 일괄 치환 기능 (Ctrl+F, Ctrl+H)
- ✅ **다양한 내보내기**: PDF, Word(.docx), 한글(.hwpx 서술식·개조식) 지원 (저장 경로 선택 대화창)
- ✅ **파일 관리**: 마크다운 파일 열기/저장, 한글(.hwpx)·Word(.docx) 문서를 마크다운으로 불러오기
- ✅ **네이티브 수식·각주·차트**: 수식은 한/글 수식·Word 수식(OMML)으로, 각주는 각 프로그램의 각주로, ```` ```chart ```` 블록은 편집 가능한 차트로 내보내기
- ✅ **표기·문체 검사**: 공문서 표기법(날짜·시각·금액·외래어 등)과 개조식 문체(‘∼다’ 종결·당위 종결 등) 검사 패널
- ✅ **내보내기 자체 검사**: 파일을 저장하기 전에 패키지 구조·XML·id 참조를 스스로 점검

## 기능 목록

### 1. 실시간 마크다운 미리보기
- GitHub Flavored Markdown (GFM) 완벽 지원
- 입력 즉시 오른쪽 프리뷰 영역에 렌더링
- Syntax Highlighting 지원

### 2. 스크롤 동기화
- 왼쪽 에디터를 스크롤하면 오른쪽 프리뷰도 자동으로 스크롤
- 오른쪽 프리뷰를 스크롤하면 왼쪽 에디터도 자동으로 스크롤
- 스크롤 비율을 기준으로 정확하게 동기화
- 무한 루프 방지 메커니즘으로 부드러운 스크롤 제공

### 3. 파일 관리

#### 파일 열기
- **버튼 클릭**: 상단 "파일 열기" 버튼으로 .md, .markdown, .txt, .hwpx, .docx 파일 선택
- **드래그 앤 드롭**: 에디터 영역에 파일을 드래그하여 바로 열기
- 파일 열기 시 자동으로 파일명 표시 및 히스토리 초기화
- **한글(.hwpx)·Word(.docx) 불러오기**: 브라우저 안에서 바로 마크다운으로 변환 (서버 전송 없음)
  - 제목(한/글 개요 문단·「개요 N」 스타일, Word 제목 스타일) → `#`∼`######`
  - 굵게·기울임·취소선·위/아래 첨자, 글머리·번호 목록, 인용·코드(Word), 하이퍼링크, 각주 → `[^n]`
  - 표는 GFM 표로, 병합 셀·여러 줄 셀이 있으면 HTML 표(`colspan`·`rowspan`)로
  - 그림은 data URL 이미지로, 수식은 LaTeX(`\(...\)`)로 근사 변환
  - 이 편집기의 한글(서술·개조)·Word 내보내기 결과를 다시 열면 원래 마크다운에 가깝게 돌아옴(표지·배너의 제목, 개조식 번호 박스·부호 정리)
  - 구형 HWP·DOC(바이너리)는 한/글·Word에서 .hwpx·.docx로 저장한 뒤 열기

#### 파일 저장 및 내보내기
- **MD 저장**: 현재 내용을 마크다운(.md) 파일로 저장 (저장 경로 선택 대화창)
- **PDF**: 프리뷰를 PDF 문서로 내보내기 (저장 경로 선택 대화창)
  - 페이지 나누기 최적화: 단락, 제목, 리스트 항목이 페이지 중간에 잘리지 않음
- **Word**: 서식이 적용된 .docx 형식으로 내보내기 (저장 경로 선택 대화창)
  - 맑은 고딕 12pt 본문, 파란색 제목 체계(제목 1~6), 회색 격자 표 + 하늘색 머리행
  - 가운데 정렬 "페이지 X / Y" 바닥글, A4 페이지 설정
  - 글머리/번호 목록, 코드 블록(Consolas), 인용문, 이미지, 목차 책갈피 링크 지원
  - 수식은 Word 수식(OMML)으로 변환해 Word 수식 편집기에서 다시 편집 가능
  - 각주는 Word 각주(footnotes.xml), ```` ```chart ```` 블록은 Word 차트, 병합 셀(`colspan`·`rowspan`)은 가로·세로 병합으로 변환
- **한글(서술)**: 서술식 발간물(책자) 서식의 .hwpx로 내보내기 (저장 경로 선택 대화창)
  - `#` 제목마다 크림색 챕터 표지 블록(주황 번호 배지 + 청록 제목, 새 페이지에서 시작)
  - `##` 제목은 가/나/다 주황 배지 + 남색 섹션 제목 + 연회색 밑줄 배너
  - `<그림 N>`·`<표 N>`으로 시작하는 문단은 가운데 남색 캡션, `출처:` 문단은 가운데 회색 소자로 자동 서식
  - 주황 머리행 표(흰 글자, 가로 연회색 줄, 머리행 반복), 하단 중앙 주황 쪽번호
  - 목록은 미리보기와 같은 계층(□→○→●, 1→1.1→1.1.1)으로 변환
- **한글(개조)**: 개조식 정부 보고서(안건) 서식의 .hwpx로 내보내기 (저장 경로 선택 대화창)
  - `#` 제목은 「◈ 제목」 한 줄(◈ 자동 접두, 테두리 없음), 제목 바로 아래 `>` 인용은 우측 부제(일자·부서)
  - ㅁ 줄(`##`)은 번호 박스 ⌈1⌉⌈2⌉… + 남색 굵은 고딕 16pt, ㅇ 줄머리 `(설계)` 같은 (라벨)은 청색 굵게, - 줄 라벨은 검정 굵게, 본문 안 괄호 부연 `(부산 기장군)`·`(100MWe)`은 13pt 작은 글자
  - 계층은 ㅁ(0칸) / ㅇ(1칸) / -(2칸) 3단, ※·`*`·`**`(4칸)는 계층이 아니라 바로 위 줄의 보충
  - `##`→ㅁ(16pt), `###`→ㅇ, `####`→-, `#####`→· 걸어쓰기 헤딩, 마커 없는 목록은 직전 줄의 다음 수준(ㅇ 아래 목록 → -)부터 ㅁ / ㅇ / - / · 자동 부여
  - 문단·목록이 ㅁ/ㅇ/▸/· 등 마커로 시작하면 그 마커와 수준을 보존(□·○ 등 이형 마커도 입력 허용)
  - 개조식 초안을 코드블럭(```)에 그대로 붙여 넣으면 줄머리 마커를 읽어 계층 문단으로 펼침 — `**강조**`·`***청색 강조***`도 반영
  - 문단 여백은 ㅁ 앞 5pt·ㅇ 앞 6pt·※/`*` 앞 2pt를 자동 삽입(빈 줄은 무시), `(5)`·`(6)`·`(2)`만 적은 줄은 그 pt 크기의 빈 문단으로 바꿔 여백을 직접 지정
  - `※ 부연`·`* 각주`·`** 둘째 각주`는 부모 수준과 무관하게 ㅇ 본문 시작선에 맞춘 12pt 맑은 고딕 회색 소자, ※가 연달아 오면(갈래별 줄) 둘째 줄부터 ※ 없이 앞 줄 본문에 이어 씀, `⇨/→` 문단은 청색 볼드 화살표, `***강조***`는 청색 볼드
  - 범위 물결은 `∼`(U+223C)로 통일 — `’24~’26`·`300~500MWe`·`(~’30)`은 `’24 ∼ ’26`·`300 ∼ 500MWe`·`(∼’30)`으로, 앞이 공백인 「약」 용법(`~100 MWe`)은 그대로
  - `## 붙임1 제목`·`[붙임1] 제목`은 남색 라벨 배너, 표는 청회색 머리행 + 검정 격자(숫자·짧은 열 가운데)
  - 휴먼명조 15pt 본문 + HY헤드라인M 제목, 하단 중앙 "- 1 -" 쪽번호
  - 부호(ㅁ 번호 박스·ㅇ·-·※) 뒤는 공백 대신 탭 — 내어쓰기 폭을 부호 글자 폭에 맞추고 자동 탭을 써서 둘째 줄이 첫 줄 본문 시작선에 정확히 맞음
  - 날짜(`2026. 1. 22.`)·금액(`3억 원`)·시각 범위·범위 물결(`’24 ∼ ’26`)의 공백은 한/글 묶음 빈칸으로 저장해 줄 끝에서 갈라지지 않음(보이는 간격은 그대로)
- 두 한글 서식 공통
  - 이미지 BinData 삽입 — PNG·JPEG·GIF·BMP는 원본 바이트 그대로(사진 용량 증가 없음), 그 밖의 형식은 PNG로 변환
  - 수식은 한/글 수식 개체(수식 편집기 스크립트)로 변환 — `\frac`·`\sqrt`·첨자·그리스 문자·`\sum`·`\int`·행렬(`pmatrix` 등)·`\left( \right)` 지원
  - 각주 `[^1]`은 한/글 각주, 외부 링크는 한/글 하이퍼링크 필드(Ctrl+클릭으로 열림, 인쇄용 `(URL)` 병기 유지), ```` ```chart ```` 블록은 한/글 차트
  - 병합 셀(`colspan`·`rowspan`) 지원, 2행 이상 표는 쪽 경계에서 나뉘고 머리행 반복(글자처럼 취급하지 않는 배치)
  - 제목은 한/글 개요 문단으로 저장되어 「문서 찾아가기」에 나타남(개요 번호는 붙지 않음)
  - XML 항목은 DEFLATE 압축(mimetype만 무압축)해 파일 크기 축소
- 한컴오피스·Word가 읽는 OWPML(HWPX)·OOXML(DOCX) 표준 패키지를 외부 라이브러리 없이 브라우저에서 직접 생성하고, 저장 전 자체 검사(XML 형식, mimetype·필수 파일, secCnt·itemCnt, 글자·문단·테두리·그림·차트 id 참조, Word 관계 파일)를 통과한 경우에만 저장
- File System Access API 미지원 브라우저에서는 자동 다운로드로 폴백

### 4. 자동 목차 생성

문서에 `<!-- TOC -->` 주석을 추가하면 자동으로 목차가 생성됩니다.

```markdown
# 문서 제목

<!-- TOC -->
자동으로 생성될 위치
<!-- /TOC -->

## 섹션 1
### 하위 섹션 1.1

## 섹션 2
```

- 모든 헤딩(#, ##, ###...)을 자동으로 감지
- 들여쓰기가 적용된 계층적 목차 생성
- 클릭 가능한 앵커 링크로 변환
- 실시간 업데이트 (헤딩 추가/삭제 시 자동 반영)

### 5. 수학 수식 지원

LaTeX 문법으로 수학 수식을 작성하면 KaTeX로 자동 렌더링됩니다.

#### 인라인 수식
`\(...\)` 구문을 사용하여 텍스트 내에 수식 삽입:
```markdown
질량-에너지 등가 원리는 \(E = mc^2\) 입니다.
```

#### 블록 수식
`$$ ... $$` 구문을 사용하여 수식 작성 (줄바꿈 지원):
```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

#### 지원 기능
- **복잡한 수식**: 분수, 적분, 합, 행렬 등 모든 LaTeX 수식 지원
- **줄바꿈 지원**: `$$ ... $$` 사이에 줄바꿈 가능 (복잡한 수식용)
- **그리스 문자**: α, β, γ, Δ, Σ 등
- **특수 기호**: ∞, ±, ≤, ≥, ∈, ∀, ∃ 등
- **실시간 렌더링**: 입력 즉시 수식 프리뷰
- **에러 처리**: 잘못된 수식도 안전하게 표시

#### 수식 예제
```markdown
이차방정식의 해:
\(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)

피타고라스 정리: \(a^2 + b^2 = c^2\)

행렬 (여러 줄):
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

#### 표에서 통화·퍼센트와 수식 함께 쓰기

단일 `$`는 통화 기호로 그대로 표시됩니다. 수식 안에서 퍼센트 기호를 표시하려면 `\%`로 작성합니다.

```markdown
| 항목 | 값 |
|---|---:|
| 가격 | $100 |
| 할인율 | 25% |
| 계산식 | \(100 \times 25\% = 25\) |
```

### 6. 강력한 편집 기능

#### 툴바 버튼
- **되돌리기/다시실행**: Undo/Redo 기능으로 편집 히스토리 관리
- **텍스트 서식**: 굵게, 기울임
- **제목**: H1, H2 헤더
- **목록**: 순서 있는 목록, 순서 없는 목록
- **코드**: 인라인 코드, 코드 블록
- **인용구**: 블록 인용
- **목차**: 자동 목차 주석 삽입
- **수식**: 수학 수식 삽입 (`\(E = mc^2\)`)
- **각주**: 다음 번호의 `[^n]` 참조를 넣고 정의 줄(`[^n]: 내용`)을 문서 끝에 추가
- **차트**: ```` ```chart ```` 블록 견본 삽입
- **검사**: 표기법·개조식 문체 검사 패널 열기/닫기

#### 키보드 단축키
- `Ctrl+Z` / `Cmd+Z`: 되돌리기
- `Ctrl+Y` / `Cmd+Y` 또는 `Ctrl+Shift+Z`: 다시실행
- `Ctrl+B` / `Cmd+B`: 굵게
- `Ctrl+I` / `Cmd+I`: 기울임
- `Ctrl+F`: 찾기
- `Ctrl+H`: 찾아 바꾸기

### 7. 찾기 및 바꾸기

#### 찾기 기능
- **텍스트 검색**: 에디터에서 단어나 문구 검색
- **실시간 검색**: 입력하는 즉시 검색 결과 표시
- **매치 카운트**: 찾은 항목 개수 표시 (예: "3/10")
- **탐색 기능**: 이전/다음 버튼으로 검색 결과 이동
- **자동 하이라이트**: 현재 위치 자동 선택 및 스크롤

#### 바꾸기 기능
- **단일 바꾸기**: 현재 선택된 항목 하나만 바꾸기
- **전체 바꾸기**: 모든 매치 항목을 한 번에 바꾸기
- **히스토리 지원**: 바꾸기 후 되돌리기(Undo) 가능

#### 키보드 단축키
- `Ctrl+F`: 찾기 패널 열기
- `Ctrl+H`: 찾아 바꾸기 패널 열기
- `Enter`: 다음 항목 찾기
- `Shift+Enter`: 이전 항목 찾기
- `Esc`: 패널 닫기

### 8. 크기 조절 가능한 분할 창
- 에디터와 프리뷰 사이의 구분선을 드래그하여 비율 조정
- 프리뷰와 목차 사이의 구분선을 드래그하여 TOC 창 너비 조정
- 데스크톱 초기 화면은 에디터와 프리뷰를 1:1 비율로 표시
- 최소 20%, 최대 80%까지 조절 가능
- 마우스, 터치, 펜 및 키보드 방향키로 크기 조절

### 9. 히스토리 관리
- 최대 100개의 편집 히스토리 저장
- 디바운싱(500ms)으로 효율적인 히스토리 관리
- 커서 위치까지 정확하게 복원

### 10. 각주와 차트

````markdown
[^1]: 각주 내용 — 미리보기에서는 문서 끝 목록, Word·한글에서는 실제 각주

```chart

cat: 1분기, 2분기, 3분기
````

- 숫자가 아닌 값이 있으면 차트로 바꾸지 않고 코드블록 그대로 표시

### 11. 표기·문체 검사

툴바의 **검사** 버튼으로 패널을 열면 입력할 때마다 원고를 검사하고, 항목을 누르면 해당 줄로 이동합니다(조언용이며 내보내기는 막지 않음).

| 구분 | 주요 규칙 |
|------|-----------|
| 표기법(편람) | 날짜 온점 띄어쓰기·0 표기·끝 마침표·하이픈 날짜, 오전/오후·24시·쌍점 띄어쓰기, ‘천원’·금액 한글 병기(자동 변환값 제시), 붙임 쌍점, 물결표와 ‘까지’ 중복, 외국어 병기 순서, 두음법칙(년도→연도), 외래어 40종·차별 표현 25종, 줄표·강조 남발 |
| 개조식 문체 | ‘∼다’ 서술형 종결, ‘∼해야 한다’ 당위 종결, 추상어 대조 수사, 물음표·느낌표, 대구 슬로건, 항목 70자·결론 60자 초과, 리드문 형식, 글자 날짜(2026년 8월) |
| 공문 엄격(선택) | 연도 두 자리(’24) 표기 금지 |

- 범위 물결은 이 편집기 관행(`’24 ∼ ’26`, 앞뒤 띄움)을 따르므로 붙여쓰기를 요구하지 않고, ASCII `~` 범위만 `∼`로 바꾸도록 안내
- 코드블록은 건너뛰되 언어 지정 없이 붙여 넣은 개조식 초안(ㅁ/ㅇ/- 줄)은 검사

## 사용 방법

### 기본 사용

1. **마크다운 파일 열기**
   - 상단의 "파일 열기" 버튼 클릭하여 .md 파일 선택
   - 또는 에디터 영역에 파일을 드래그 앤 드롭
   - 파일명이 헤더에 자동으로 표시됨

2. **마크다운 작성**
   - 왼쪽 에디터 창에 마크다운 텍스트 입력
   - 오른쪽 프리뷰 창에서 실시간으로 결과 확인

3. **목차 추가하기**
   - 툴바에서 목차 버튼(리스트 아이콘) 클릭
   - 또는 직접 `<!-- TOC -->` 와 `<!-- /TOC -->` 주석 작성
   - 자동으로 문서의 모든 헤딩이 목차로 생성됨

4. **서식 적용**
   - 텍스트를 드래그하여 선택
   - 툴바 버튼 클릭으로 마크다운 문법 자동 삽입
   - 또는 키보드 단축키 사용

5. **창 크기 조절**
   - 중앙의 회색 구분선을 마우스로 드래그
   - 원하는 비율로 에디터/프리뷰 크기 조정

6. **문서 저장**
   - **MD 저장**: 마크다운 파일로 저장
   - **PDF**: PDF 문서로 내보내기
   - **Word**: 서식이 적용된 Word 문서(.docx)로 내보내기
   - **한글(서술)**: 서술식 발간물(책자) 서식의 한글 문서(.hwpx)로 내보내기
   - **한글(개조)**: 개조식 정부 보고서 서식의 한글 문서(.hwpx)로 내보내기

7. **개조식 초안 → 한글(개조)**
   - 아래처럼 ㅁ / ㅇ / - 3단 + ※·`*` 보충으로 쓴 개조식을 코드블럭에 붙여 넣고 **한글(개조)** 를 누르면 계층·여백이 적용된 .hwpx가 생성됩니다.

   ````markdown
   ```
   ㅁ 핵융합 : 국제표준 동향 및 한국의 제안 가능 분야

    ㅇ (해외 동향) 핵융합 국제표준은 「장치 부품·시험방법」 단위의 초기 단계, 중국이 ISO 제정을 선점*
       * ISO 4233:2023에 이어 ISO 19991:2026 발표(’26.8), 12개국 전원 찬성
     - (미국·규제표준) NRC 부산물질(10 CFR Part 30) 분류, Tennessee 주 규제 발효(’26.6)
       ※ Part 30 개정 최종규칙 공표 예상 ’27.12, 그 전까지 Agreement State 개별 인허가
   ```
   ````

   - 코드블럭 없이 마크다운으로 써도 됩니다: `##`/`ㅁ` 줄이 ㅁ, `###`/`ㅇ` 줄이 ㅇ, 그 아래 `-` 목록이 -, `※`·`*`로 시작하는 문단이 보충 줄이 됩니다.

### 마크다운 문법 예제

```markdown
# 제목 1
## 제목 2

**굵은 텍스트**
*기울임 텍스트*
~~취소선 텍스트~~

- 순서 없는 목록 (□)
- 항목 2
  - 중첩 항목 (○)
    - 3단계 항목 (●)

1. 순서 있는 목록 (1로만 써도 자동 번호 매김)
1. 항목 2
   1. 중첩 항목 (1.1로 표시)
   1. 항목 2-2 (1.2로 표시)
      1. 3단계 항목 (1.2.1로 표시)
1. 항목 3

`인라인 코드`

\`\`\`javascript
// 코드 블록
function hello() {
  console.log("Hello, World!");
}
\`\`\`

> 인용구
```

#### 리스트 스타일
- **불릿 리스트**: 1단계 □ (사각형) → 2단계 ○ (원형) → 3단계 ● (채움)
- **순서 리스트**: 1단계 1, 2, 3... → 2단계 1.1, 1.2... → 3단계 1.1.1, 1.1.2...
- 모든 항목을 `1.`로 작성해도 자동으로 번호가 매겨집니다

## 코드 아키텍처

### 주요 컴포넌트

1. **수학 수식 렌더링 시스템**
   - `renderMath()`: KaTeX를 사용한 LaTeX 수식 렌더링
   - 인라인 수식 (`\(...\)`) 및 블록 수식 (`$$...$$`) 지원
   - 실시간 수식 프리뷰
   - 에러 처리 및 안전한 fallback

2. **자동 목차 생성 시스템**
   - `generateTOC()`: 마크다운 헤딩을 파싱하여 목차 생성
   - `&lt;!-- TOC --&gt;` 주석 감지 및 자동 교체
   - 계층적 들여쓰기와 앵커 링크 생성
   - 실시간 업데이트 및 한글/영문 지원

3. **파일 관리 시스템**
   - `openMarkdownFile()`: FileReader API를 사용한 파일 읽기
   - `saveMarkdownFile()`: Blob API를 사용한 파일 저장
   - `setupDragAndDrop()`: 드래그 앤 드롭 이벤트 처리

4. **히스토리 관리 시스템**
   - `saveToHistory()`: 현재 상태를 히스토리에 저장
   - `undo()` / `redo()`: 되돌리기/다시실행
   - `restoreState()`: 이전 상태 복원
   - 최대 100개 히스토리 유지, FIFO 방식

5. **마크다운 에디터**
   - `insertMarkdown()`: 커서 위치에 마크다운 문법 삽입
   - 텍스트 선택 시 자동으로 감싸기
   - 커서 위치 자동 조정
   - TOC 및 수식 주석 자동 삽입

6. **리사이저**
   - 마우스 드래그 이벤트 처리
   - Flexbox 기반 동적 크기 조절
   - 20%~80% 범위 제한

7. **내보내기 기능**
   - `exportToPDF()`: html2pdf.js를 사용한 PDF 생성
   - `exportToWord()`: 브라우저에서 OOXML(.docx) 패키지를 직접 생성
     - `buildDocxFromPreview()`: 프리뷰 DOM을 document.xml로 변환 (제목/목록/표/코드/수식/이미지/하이퍼링크)
     - 내장 스타일 견본: 맑은 고딕 본문, 파란 제목, 격자 표(머리행 음영), "페이지 X / Y" 바닥글
     - `docxBuildZip()`: 외부 라이브러리 없이 ZIP(STORE + CRC-32) 패키징
   - `exportToHwpx()`/`exportToHwpxGov()`: 브라우저에서 OWPML(.hwpx) 패키지를 직접 생성 (`exportHwpxWithTheme()` 공용)
     - `buildHwpxFromPreview(root, title, theme)`: 프리뷰 DOM을 header.xml(글꼴·글자/문단 모양·테두리)과 section0.xml(본문)로 변환. theme = `'book'`(서술식) | `'gov'`(개조식)
     - 서술식: `hwpxChapterCover()`/`hwpxSectionBanner()` 크림색 챕터 표지·가나다 배지 배너, `hwpxTableToXml()` 주황 머리행 표, `hwpxListToXml()` □○● 목록
     - 개조식: `hwpxGovTitle()` ◈ 제목 줄, `hwpxGovLevel0()` ㅁ 번호 박스, `hwpxGovSplitLabel()`/`hwpxGovParenRuns()` (라벨)·괄호 부연 서식, `hwpxGovBlocksToXml()` ㅁ/ㅇ/-/· 걸어쓰기·※ 부연·⇨ 화살표·`(5)(6)(2)` 여백 줄, `hwpxGovNotePp()` ※·*·** 보충 줄 위치, `hwpxGovPreToXml()`→`hwpxGovTextLineToXml()` 코드블럭 개조식 평문 펼치기, `hwpxGovNormalize()` 범위 `~`→`∼`, `hwpxGovAttachBanner()` 붙임 배너, `hwpxGovTableToXml()` 청회색 머리행 격자 표
     - 공통: `hwpxRenderTable()` 표 렌더러, `hwpxPicRun()` 이미지(BinData), 한/글 기본 템플릿과 동일한 참조 서식(글꼴 7언어축, 기본 문단 20종, 스타일 23종) 내장
     - ZIP 패키징은 Word 내보내기의 `docxBuildZip()`을 재사용 (mimetype을 첫 무압축 항목으로 배치)

### 2026-09-15

- **한글(개조) 서식을 정부 문서 원본 이미지에 맞춰 재정리**: `#` 제목은 「◈ 제목」 한 줄(테두리 없음), ㅁ 줄은 번호 박스 + 남색 굵은 고딕, ㅇ 줄머리 (라벨)은 청색 굵게(- 줄은 검정 굵게), 본문 괄호 부연은 13pt 작은 글자, ※·`*` 보충은 12pt로 ㅇ 본문 시작선에 정렬하고 연속 ※ 갈래는 둘째 줄부터 마커 없이 이어쓰기, 열린 범위 `’39~)`도 `∼`로 통일
- **한글(개조) 내보내기를 정부 문서 개조식 규격에 맞게 정비**: ㅁ(U+3141) / ㅇ / - 3단 계층 + ※·`*`·`**` 보충 체계로 통일
  - `##` 헤딩과 `ㅁ` 줄이 ㅁ(기존 □)로 변환되고 □·○ 등 이형 마커는 입력 시 그대로 보존, 마커 없는 목록은 직전 줄의 다음 수준부터 부여(ㅇ 아래 목록이 ㅇ으로 반복되던 문제 해결)
  - `※`·`*`·`**` 보충 줄은 부모 수준과 무관하게 「  - 」 본문 시작선(4칸)에 정렬, `**` 둘째 각주 지원
  - 문단 여백을 원문 빈 문단 글꼴 크기와 같은 ㅁ 앞 5pt·ㅇ 앞 6pt·보충 앞 2pt로 조정(- 줄 사이 여백 없음), `(5)`·`(6)`·`(2)` 여백 지정 줄은 해당 pt 빈 문단으로 변환
  - 개조식 초안을 코드블럭째 붙여 넣으면 줄머리 마커·들여쓰기를 읽어 계층 문단으로 펼침(마커 줄 6할 이상일 때, 그 외 코드는 기존처럼 회색 고정폭 유지), `**강조**`·`***청색 강조***` 반영
  - 범위 물결 `~`를 `∼`(U+223C)로 통일(`’24 ∼ ’26`, `(∼’30)`), 앞이 공백인 「약」 용법(`~100 MWe`)은 유지
  - 검증: Chromium에서 코드블럭·마크다운·일반 코드 3종 입력으로 내보낸 .hwpx의 문단 여백·내어쓰기·글자 모양을 확인, `tests/hwpx_export.test.js` 갱신

  - 공통: 한/글 기본 템플릿과 동일한 참조 서식(글꼴 7언어축·기본 문단 20종·스타일 23종)을 내장한 OWPML 표준 패키지를 외부 라이브러리 없이 생성, 이미지 BinData 삽입, ZIP 패키저는 Word 내보내기와 공유
  - 검증: Chromium에서 두 서식의 실제 내보내기를 구동해 생성한 .hwpx를 python-hwpx 로더·패키지 검증기(ZIP CRC/mimetype/container/XML 파싱/ID 참조 무결성/셀 폭 합계)로 확인, `tests/hwpx_export.test.js` 회귀 테스트 추가
